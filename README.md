# Рабочий график

Android-приложение: календарь смен, доп. задачи с ценами и итоги по периодам выплат.
Работает без интернета и без регистрации, данные хранятся на телефоне.
APK собирает GitHub: на компьютере ничего устанавливать не нужно.

## Что умеет

- **Календарь месяца.** Рабочие дни подсвечены, в клетке видны часы и сумма за день.
- **Нажатие на день.** Время начала и конца, выбор доп. задач из списка (с количеством и временем выполнения), заметка.
- **Настройки.** Почасовая ставка, время смены по умолчанию, список доп. задач с ценами, правила периодов выплат.
- **Итоги.** Заработок по периодам выплат, разбивка на часы и задачи, отметка «выплачено», сумма, которая ещё ждёт выплаты.
- **Копия данных.** Выгрузка в файл через меню «Поделиться» и загрузка из файла.

## Как получить APK

1. Создайте на GitHub пустой репозиторий (можно приватный) и загрузите в него все файлы проекта в ветку `main`.
   Папка `.github` скрытая, она обязательно должна попасть в репозиторий.

   ```bash
   git init
   git add .
   git commit -m "Рабочий график"
   git branch -M main
   git remote add origin https://github.com/<ваш-логин>/<имя-репозитория>.git
   git push -u origin main
   ```

2. Откройте вкладку **Actions**. Сборка **Build Android APK** запустится сама после пуша и займёт около 5–10 минут.
   Если не запустилась, откройте её в списке слева и нажмите **Run workflow**.
3. Когда сборка станет зелёной, откройте справа на главной странице репозитория раздел **Releases**.
   Там лежит релиз «Рабочий график (APK)» с файлом `worklog.apk`. Тот же файл есть в Actions: откройте нужный запуск и скачайте архив из блока Artifacts.
4. Скачайте `worklog.apk` на телефон и откройте его. Android попросит разрешить установку из этого источника (браузера или «Файлов»).
   Play Protect может предупредить, что приложение неизвестное. Нажмите «Всё равно установить».

## Как обновить приложение

Измените файлы и сделайте новый пуш в `main`. GitHub соберёт новый APK, его нужно скачать и установить поверх старого.
Данные при этом сохраняются, потому что все сборки подписаны одним и тем же ключом из `signing/debug.keystore`.
Не удаляйте и не меняйте этот файл: с другим ключом Android не даст обновить приложение, и придётся удалять его вместе с данными.

## Как считаются периоды

День выплаты входит в закрывающийся период. По умолчанию выплаты 5-го и 20-го:

| Период | Выплата |
| --- | --- |
| с 6-го по 20-е число включительно | 20-го числа |
| с 21-го по 5-е число следующего месяца включительно | 5-го числа |

Числа выплат меняются в **Настройках → Периоды выплат**.

Сумма за день = (часы смены − время доп. задач) × ставка + сумма выбранных доп. задач.
Время задач вычитается из часов, потому что задача оплачивается по своей цене, а не по ставке.
Ставка берётся из настроек и действует для всех дней: если её изменить, пересчитаются и прошлые дни.
Цены задач запоминаются в самом дне и при смене цены в настройках не меняются.
Смена через полночь (например, 22:00–02:00) считается правильно.

## Важно про данные

Данные лежат только внутри приложения. Если удалить приложение, очистить его данные или сменить телефон, они пропадут.
Время от времени нажимайте **Настройки → Сохранить копию** и сохраняйте файл в «Файлы», на Диск или отправляйте себе в мессенджер.
На новом телефоне нажмите **Загрузить копию** и выберите этот файл.

## Устройство проекта

```
index.html, styles.css, app.js   само приложение (обычная веб-страница внутри оболочки Capacitor)
capacitor.config.json            название и идентификатор приложения
package.json                     зависимости Capacitor
android-res/                     иконки приложения
signing/debug.keystore           ключ подписи, одинаковый для всех сборок
scripts/                         build-web.mjs собирает папку www, apply-icons.mjs ставит иконку
.github/workflows/android.yml    сборка APK на GitHub
```

Папки `android/` и `www/` создаются во время сборки и в репозиторий не попадают.

## Проверка интерфейса на компьютере

Интерфейс можно открыть и в браузере, чтобы быстро посмотреть изменения:

```bash
python3 -m http.server 8080
```

Откройте http://localhost:8080. В браузере кнопка «Сохранить копию» скачивает файл напрямую.
